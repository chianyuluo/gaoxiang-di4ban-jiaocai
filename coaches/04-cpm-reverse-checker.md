# 关键路径逆向检查器

## R｜原文/考纲锚点（≤150字）

关键路径是网络图中总持续时间最长的路径。正向计算：ES 取各紧前 EF 的**最大值**，EF = ES + 工期；反向计算：LF 取各紧后 LS 的**最小值**，LS = LF − 工期。总时差 TF = LS − ES（或 LF − EF）；自由时差 FF = 紧后最早开始的最小值 − 本活动 EF。

**注**：R 段只保留"正向取大、反向取小"和两个时差公式。考生真正出错的地方不在公式本身，而在**计算方向的反转**和**总时差/自由时差的混用**。

## I｜考生通常卡在哪

关键路径是"看起来会、一算就错"的典型。四个断点：

**断点一：正向取错方向。** 一个活动有多个紧前时，ES 应取各紧前 EF 的**最大值**；取最小或平均，后续参数全部偏移。

**断点二：反向取错方向。** 一个活动有多个紧后时，LF 应取各紧后 LS 的**最小值**；延续正向"取大"习惯就会错。

**断点三：总时差与自由时差混用。** TF = LS − ES；FF = 紧后最早开始最小值 − 本活动 EF。题目问 TF 却算了 FF。

**断点四：多关键路径与虚活动。** 多条同长路径只写一条；工期为 0 的虚活动被跳过，紧后关系断裂。

**经验分布**：四类断点大致为 断点一 35%、断点二 30%、断点三 25%、断点四 10%。追问按此优先级设计。

## A1｜正确过程示范

**题干**：活动 A(3) 无紧前；B(4) 紧前 A；C(2) 紧前 A；D(5) 紧前 B、C；E(1) 紧前 D。求关键路径、总工期、各活动总时差。

**1. 正向（取最大）**
- A：ES=0，EF=3
- B：ES=3，EF=7
- C：ES=3，EF=5
- D：ES=max(7,5)=**7**，EF=12
- E：ES=12，EF=13
- 总工期 = max(EF) = **13**

**2. 反向（取最小）**
- E：LF=13，LS=12
- D：LF=12，LS=7
- B：LF=7，LS=3
- C：LF=7，LS=5
- A：LF=min(3,5)=**3**，LS=0

**3. 总时差 TF = LS − ES**
- A 0；B 0；C 2；D 0；E 0

**4. 关键路径**：TF=0 的 A、B、D、E → **A→B→D→E**，总工期 13 天。

**关键动作**：D 的 ES 取 `max(7,5)`；A 的 LF 取 `min(3,5)`。这两个方向是整题的枢纽。

## A2｜反例库

**反例 A：正向取最小**
- 过程：D 的 ES = min(7,5) = 5，EF=10。
- 错在哪：D 必须等 B、C 都完成，ES 应取 max=7；取小会低估总工期。
- 追问："D 要开始，是只要 B 或 C 一个完成，还是两个都必须完成？都必须完成，ES 取较大还是较小？"

**反例 B：反向延续取大**
- 过程：A 的 LF = max(3,5) = 5，LS=2。
- 错在哪：A 必须在 B、C 中最早开始者之前完成，LF 应取 min=3；取大会把 TF 算成 2，关键路径判断错。
- 追问："A 最晚什么时候完成才不拖累 B 和 C？取较早还是较晚的那个？"

**反例 C：总时差/自由时差混用**
- 过程：问 C 的总时差，用"紧后最早开始最小值 − C 的 EF"得 2，当作 TF。
- 错在哪：本题数值碰巧相同，但公式来源不同；紧后最早/最晚不一致时两者会不同。
- 追问："题目问的是总时差还是自由时差？你用的公式是 LS−ES，还是'紧后最早开始最小值−本活动 EF'？"

**反例 D：多关键路径只写一条 / 虚活动被跳过**
- 过程：两条路径工期都是 13，只写一条；或工期 0 的虚活动被跳过。
- 错在哪：多关键路径必须全部列出；虚活动是逻辑关系载体，不能跳过。
- 追问："还有哪条路径的总持续时间也等于总工期？图中工期为 0 的虚活动，你有没有纳入紧前紧后？"

## E｜执行流程（每层只问一个问题）

**第 1 层：正向取大**
> "挑一个有两个以上紧前的活动，你的 ES 是怎么取的——最大值，还是最小/平均？"
- 取小/平均 → 反例 A；取大 → 第 2 层。

**第 2 层：反向取小**
> "挑一个有两个以上紧后的活动，你的 LF 是怎么取的——最小值，还是最大值？"
- 取大 → 反例 B；取小 → 第 3 层。

**第 3 层：时差概念**
> "这个时差，题目问的是总时差还是自由时差？你用的是 LS−ES，还是'紧后最早开始最小值−本活动 EF'？"
- 不匹配 → 反例 C；匹配 → 第 4 层。

**第 4 层：完整性与虚活动**
> "关键路径有几条？图中工期为 0 的虚活动，你计算时保留了吗？"
- 遗漏 → 反例 D；完整 → 第 5 层。

**第 5 层：结论表述**
> "用一句完整的话写出关键路径和总工期。若问'哪些活动可延迟而不影响总工期'，依据是总时差还是自由时差？"

## 使用示例

**考生**："我算的关键路径是 A→C→D→E，总工期 12 天。D 的 ES 我取 5，因为 C 的 EF 是 5。"

**响应（第 1 层）**："D 的紧前除了 C，还有 B。B 的 EF 是多少？D 要开始，是只需要 C 完成，还是 B 和 C 都必须完成？如果都必须完成，ES 应取较大的还是较小的？"

考生答"B 的 EF 是 7，必须都完成" → 引导其发现 ES=max(7,5)=7，总工期 13，关键路径含 B。
