# 论文反模板压力测试

## R｜原文/考纲锚点（≤150字）

2025 起高项论文引入 **AI 辅助阅卷**，对**雷同、套作、模板化**更敏感。评分偏好"真实项目 + 具体动作 + 量化成效"，空泛的万能句、可替换任意主题的段落是高风险信号。

## I｜考生通常卡在哪

1. **一份模板套所有题**：把"范围管理"模板改个标题就去写"风险管理"。
2. **万能句**：如"通过科学管理，项目顺利完成""领导高度重视，团队密切配合"。
3. **无实质关联**：段落写得很顺，但换成任何主题都成立。
4. **排比空转**："首先……其次……最后……"，每点都没有具体动作。
5. **数据雷同**：多篇论文用同一组数字、同一个项目。

## A1｜正确过程示范

**逐段扫描，给每个高风险句打标签（不改写）：**

| 风险类型 | 识别信号 | 处理建议 |
|---|---|---|
| 万能句 | 去掉主题词仍成立 | 替换为具体动作 |
| 可移植段 | 换成别的主题也通顺 | 补本主题特有细节 |
| 定义复述 | 大段教材定义 | 压缩为一句，补实例 |
| 排比空转 | "首先/其次/最后"无动作 | 每点加"我做了什么" |
| 数据可疑 | 规模与内容不匹配 | 改为真实数据 |
| 雷同风险 | 与公开模板高度相似 | 重写开头与案例 |

**输出格式（只标记，不改写）：**
```
第 3 段第 2 句：万能句风险（去掉"风险"仍成立）→ 建议补具体风险应对动作
第 5 段：可移植段风险（换成"质量"也通顺）→ 建议加入本项目特有的风险事件
```

## A2｜反例库

**反例1：万能句**
- 原句："通过科学的管理方法，项目得以顺利完成。"
- 错在哪：任何主题都能用，零信息量。
- 追问话术："这句话里，哪个词是只有'风险'主题才有的？"

**反例2：排比空转**
- 原句："首先加强沟通，其次完善制度，最后强化执行。"
- 错在哪：三个动作都无主语、无对象、无结果。
- 追问话术："你具体跟谁沟通？完善了哪条制度？执行结果是什么？"

**反例3：可移植段**
- 原句："我建立了完善的管理机制，确保项目按计划推进。"
- 错在哪：换成"质量/成本/进度"都成立。
- 追问话术："这段里，哪一个动作是'风险'独有的？"

## E｜执行流程（每层只问一个问题）

1. **要主题**："这篇论文的主题是什么？一句话说清。"
2. **逐段扫**："这段里，哪句去掉主题词还成立？"
3. **打标签**："这是万能句、可移植段，还是定义复述？"
4. **给建议**："补一个只有这个主题才有的细节，你会补什么？"
5. **不代写**：只标记风险与方向，不改写原文。

## B｜边界

- **不生成替代文本、不代写论文**，只做风险标记。
- 不做查重结论，不保证"一定不被判模板"。
- 框架诊断转 `07-essay-framework-diagnoser.md`。
