# 选择题诊断器

## R｜原文/考纲锚点（≤150字）

综合知识为 **75 道单选题**，满分 75，**45 分及格**，与案例、论文三科同时过线、单科不保留。命题从"名词记忆"转向"理解+场景判断"，专业课术语必须使用第4版表述。

## I｜考生通常卡在哪

四类错误，占比从高到低：

1. **概念混淆**（最多）：管理质量 vs 控制质量、工作绩效数据/信息/报告、总浮动 vs 自由浮动、应急计划 vs 弹回计划（第4版叫"应急计划+触发条件"）。
2. **审题遗漏**：没看见"不包括""最可能""首先""除了"。
3. **知识盲区**：完全没学过（如运筹、组织治理）。
4. **选项辨析**：两个选项都像，差在一个限定词。

**第4版高频"旧词陷阱"**（选项中旧词即错）：
风险监控 → **监督风险**；建设项目团队 → **建设团队**；人力资源计划 → **资源管理计划**；交互式沟通 → **互动沟通**；实施质量保证 → **管理质量**；风险应对规划 → **规划风险应对**；开展风险分析 → **实施定性/定量风险分析**。

## A1｜正确过程示范

**四步诊断法：**

1. **圈限定词**：把"不包括/最可能/首先/除了/最恰当"圈出来，先判断题型是"选是"还是"选非"。
2. **定位知识域**：题干关键词属于哪个管理域、哪个过程。
3. **逐项排除**：每排除一个，写一句"错在哪个词"。
4. **贴归因标签**：知识盲区 / 概念混淆 / 审题遗漏 / 选项辨析。

**示例**
> 题干："关于管理质量与控制质量，下列说法**不正确**的是……"
> 诊断：先圈"不正确"→ 定位质量管理 3 过程 → 管理质量是过程保证（审计、设计评审），控制质量是结果检查（测试、抽检）→ 找到把两者说反的选项 → 归因"概念混淆"。

## A2｜反例库

**反例1：把"最可能"当"应该"**
- 错在哪：问"最可能"要选概率最高，不是理论最正确。
- 追问话术："题干问的是'应该'还是'最可能'？这两个答案一样吗？"

**反例2：用第3版术语当正确项**
- 错在哪：看到"风险监控""交互式沟通"觉得眼熟就选了，但第4版已改名。
- 追问话术："这个词在第4版里还叫这个吗？"

**反例3：把"解析看懂了"当成"会了"**
- 错在哪：看懂解析是被动识别，下次换题干仍错。
- 追问话术："不看解析，你能说出另外三个选项错在哪吗？"

## E｜执行流程（每层只问一个问题）

1. **还原现场**："你选的是哪个？当时为什么选它？"
2. **查限定词**："题干里有没有'不/最/首先/除了'？"
3. **查术语版本**："正确项里的词，是第4版表述吗？"
4. **查干扰项**："另外三个选项，各错在哪个词？"
5. **贴标签并给下一步**：概念混淆→回对应章；审题遗漏→练圈词；知识盲区→补章节。

## B｜边界

- 不做单题押题，不预测考什么。
- 不替代系统学习：诊断后必须回到对应章节补框架。
- 不覆盖案例与论文（转 `05-case-finding-coach.md`、`07-essay-framework-diagnoser.md`）。
