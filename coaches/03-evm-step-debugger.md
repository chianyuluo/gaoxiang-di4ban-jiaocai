# 挣值分析步骤纠错器

## R｜原文/考纲锚点（≤150字）

挣值管理用 **PV（计划价值）、EV（挣值）、AC（实际成本）** 三个基础量：CV=EV−AC、SV=EV−PV；CPI=EV/AC、SPI=EV/PV；预测 EAC、ETC、TCPI。是案例计算题最高频考点。

**注**：考生不是不会公式，而是**取数错、标签错、典型/非典型判断错**。

## I｜考生通常卡在哪

1. **AC 当 EV**：把"实际花了多少钱"当成"完成了多少价值"。
2. **PV 与 EV 混**：PV 是"计划应完成的价值"，EV 是"实际完成的价值"。
3. **典型/非典型判断错**：题目说"按当前绩效继续"才是典型；说"剩余按原计划"是非典型。
4. **TCPI 分母错**：分母是"剩余预算"（BAC−AC 或 EAC−AC），不是 BAC。
5. **只看指数不看偏差**：CPI<1 超支，但 CV 的正负也要能说清。

## A1｜正确过程示范

**第 1 步：先定义三个量（必须写出来）**
- PV = 计划完成工作的预算价值
- EV = 实际完成工作的预算价值
- AC = 实际完成工作的实际成本

**第 2 步：偏差（减法）**
- CV = EV − AC（<0 超支）
- SV = EV − PV（<0 落后）

**第 3 步：指数（除法）**
- CPI = EV / AC（<1 超支）
- SPI = EV / PV（<1 落后）

**第 4 步：预测（先判典型/非典型）**
- 典型：EAC = BAC / CPI；ETC = EAC − AC
- 非典型：EAC = AC + (BAC − EV)；ETC = BAC − EV
- TCPI = (BAC − EV) / (BAC − AC) 或 (BAC − EV) / (EAC − AC)

**完整算例**
> BAC=100，PV=50，EV=40，AC=60。
> CV=40−60=−20（超支）；SV=40−50=−10（落后）；CPI=40/60≈0.67；SPI=40/50=0.8。
> 典型 EAC=100/0.67≈150；ETC=150−60=90；TCPI=(100−40)/(100−60)=1.5。
> 非典型 EAC=60+(100−40)=120；ETC=100−40=60。

## A2｜反例库

**反例 A：把 AC 当 EV**
- 过程：用 AC=60 当 EV，CPI=60/60=1，误判"不超支"。
- 错在哪：EV 是"完成了多少预算价值"，不是"花了多少钱"。
- 追问："EV 是完成了多少预算价值，还是花了多少钱？题干里'完成 40%'对应哪个量？"

**反例 B：典型/非典型用反**
- 过程：题目说"后续仍按当前绩效"，却用 EAC=AC+BAC−EV。
- 错在哪：没说"剩余按原计划"就是典型。
- 追问："题目有没有说'剩余工作按原计划'？没有就是典型，公式是哪个？"

**反例 C：TCPI 分母写成 BAC**
- 过程：TCPI=(BAC−EV)/BAC。
- 错在哪：TCPI 是"剩余工作 ÷ 剩余钱"，分母必须是剩余预算。
- 追问："你还剩多少钱？这个数才是分母。"

## E｜执行流程（每层只问一个问题）

**第 1 层：要定义**
> "你先说 EV、PV、AC 各是什么？"

**第 2 层：要取值**
> "这三个数分别从题干哪句话来？"

**第 3 层：要步骤**
> "先算偏差还是先算指数？把你的式子写出来。"

**第 4 层：要判断**
> "这题是典型还是非典型？依据是哪句话？"

**第 5 层：只纠错不加倍**
> 只在错的那一步提示，不重讲整章。

## 使用示例

**考生**："PV=150 万，AC=145 万，完成 70%，我算 EV=145，CV=0，结论成本持平。"

**响应（第 1 层）**："先别算。你填进 EV 的 145 万，题干原文说的是'实际花费'还是'实际完成工作'？这两个量分别叫什么？"

考生答"145 是实际花费" → 引导：EV 应为 BAC×70%，AC 才是 145；再重算 CV、CPI。
