# 挣值分析步骤纠错器

## R｜原文/考纲锚点（≤150字）

挣值管理（EVM）用 **PV（计划价值）、EV（挣值）、AC（实际成本）** 三个基础量，计算偏差 CV=EV−AC、SV=EV−PV；指数 CPI=EV/AC、SPI=EV/PV；预测 EAC、ETC、TCPI。是案例计算题的最高频考点。

## I｜考生通常卡在哪

1. **AC 当 EV**：把"实际花了多少钱"当成"完成了多少价值"。
2. **PV 与 EV 混**：PV 是"计划应该完成的价值"，EV 是"实际完成的价值"。
3. **典型/非典型判断错**：题目说"按当前绩效继续"才是典型（EAC=BAC/CPI）；说"剩余按原计划"是非典型（EAC=AC+BAC−EV）。
4. **TCPI 分母错**：分母是"剩余预算"（BAC−AC 或 EAC−AC），不是 BAC。
5. **只看指数不看偏差**：CPI<1 是超支，但 CV 的正负也要能说清。

## A1｜正确过程示范

**四步法：**

**第 1 步：先定义三个量（必须写出来）**
- PV = 计划完成工作的预算价值
- EV = 实际完成工作的预算价值
- AC = 实际完成工作的实际成本

**第 2 步：算偏差（减法，判正负）**
- CV = EV − AC（<0 超支）
- SV = EV − PV（<0 落后）

**第 3 步：算指数（除法，判与 1 的关系）**
- CPI = EV / AC（<1 超支）
- SPI = EV / PV（<1 落后）

**第 4 步：预测（先判典型/非典型）**
- 典型：EAC = BAC / CPI；ETC = EAC − AC
- 非典型：EAC = AC + (BAC − EV)；ETC = BAC − EV
- TCPI = (BAC − EV) / (BAC − AC)（按原预算完工）或 (BAC − EV) / (EAC − AC)（按新预算完工）

**示例**
> BAC=100，PV=50，EV=40，AC=60。
> CV=40−60=−20（超支）；SV=40−50=−10（落后）；CPI=40/60≈0.67；SPI=40/50=0.8；典型 EAC=100/0.67≈150。

## A2｜反例库

**反例1：把 AC 当 EV**
- 错在哪：用 60 当 EV，CPI=60/60=1，误判"不超支"。
- 追问话术："EV 是'完成了多少预算价值'，还是'花了多少钱'？"

**反例2：典型/非典型用反**
- 错在哪：题目说"后续仍按当前绩效"，却用了 EAC=AC+BAC−EV。
- 追问话术："题目有没有说'剩余工作按原计划'？没有就是典型。"

**反例3：TCPI 分母写成 BAC**
- 错在哪：TCPI 是"剩余工作 ÷ 剩余钱"，分母必须是剩余预算。
- 追问话术："你还剩多少钱？这个数才是分母。"

## E｜执行流程（每层只问一个问题）

1. **要定义**："你先说 EV、PV、AC 各是什么？"
2. **要取值**："这三个数分别从题干哪句话来？"
3. **要步骤**："先算偏差还是先算指数？把你的式子写出来。"
4. **要判断**："这题是典型还是非典型？依据是哪句话？"
5. **只纠错不加倍**：只在错的那一步提示，不重讲整章。

- 不覆盖工程经济、运筹（回 `ch21`）。
