# Chapter 2: 信息技术发展

## Core Idea
计算机软硬件、网络、存储、信息安全是底座；物联网/云计算/大数据/区块链/人工智能/虚拟现实等"新一代信息技术"是命题热点。

## Frameworks Introduced
- **新一代信息技术（6 类）**：物联网、云计算、大数据、区块链、人工智能、虚拟现实。
- **云计算服务模型**：IaaS（基础设施）/ PaaS（平台）/ SaaS（软件）——按"管到哪一层"区分。
- **大数据 4V**：Volume（体量大）/ Velocity（速度快）/ Variety（类型多）/ Value（价值密度低）。
- **区块链特征**：去中心化、不可篡改、可追溯、集体维护。

## Key Concepts
- **人工智能**：机器学习/深度学习、自然语言处理、计算机视觉。
- **物联网架构**：感知层 / 网络层 / 应用层。
- **信息安全属性**：保密性、完整性、可用性（CIA）。
- **网络协议基础**：TCP/IP 分层、常见端口。

## Mental Models
- 新技术题的答题锚点始终是"**它解决什么业务问题**"，而非技术细节；考题多考定义与特征。

## Anti-patterns
- **混淆 IaaS/PaaS/SaaS 边界**——记住：IaaS 给你虚拟机，PaaS 给你开发平台，SaaS 直接给你应用。

## Key Takeaways
1. 6 类新一代信息技术的定义与典型应用要会辨析。
2. 云计算三层服务模型及其区别。
3. 大数据 4V、区块链核心特征。
4. 信息安全 CIA 三属性。
