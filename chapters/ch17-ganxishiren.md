# Chapter 17: 项目干系人管理（4 过程）

## Core Idea
4 过程：**识别干系人 / 规划干系人参与 / 管理干系人参与 / 监督干系人参与**；干系人是项目成败关键。

## Frameworks Introduced
- **权力/利益方格**：高权高益=重点管理；高权低益=令其满意；低权高益=随时告知；低权低益=监督。
- **干系人参与度 5 级**：不知晓 → 抵制 → 中立 → 支持 → 领导（C→R→N→S→L）。
- **萨尔曼模型**：未知 / 潜伏 / 知情 / 支持 / 领导。

## Key Concepts
- **识别是持续过程**：不仅在启动，整个生命周期都要更新干系人登记册。
- **干系人参与计划**：把当前参与度拉向所需参与度的策略。
- **管理干系人参与**：沟通、协商、处理冲突、促进参与。

## Mental Models
- 干系人 = **项目许可与资源的来源**，先识别、再规划、持续监督。
- 抵制者要转化，不能忽视（最易酿成项目受阻）。

## Anti-patterns
- **只在启动识别一次干系人**——需求与权力结构会变，须持续识别与更新。
- **忽视"抵制"干系人**——未管理的抵制者会在关键节点反噬。

## Key Takeaways
1. 干系人 4 过程。
2. 权力/利益方格四格策略。
3. 参与度 5 级（C/R/N/S/L）。
4. 识别需持续进行。
