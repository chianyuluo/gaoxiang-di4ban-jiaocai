# Chapter 14: 项目沟通管理（3 过程）

## Core Idea
3 过程：**规划沟通管理 / 管理沟通 / 监督沟通**；核心是"沟通模型 + 渠道数量"。

## Frameworks Introduced
- **沟通模型**：编码 → 消息 → 介质 → 解码 → 反馈，全程贯穿"噪声"。
- **沟通方法三类**：互动沟通（实时双向）/ 推式沟通（邮件、通知单向推）/ 拉式沟通（知识库、门户自选）。
- **沟通渠道数** = n(n−1)/2（n 为干系人数）。
- **权力/利益方格**（用于沟通策略）：高权高益重点管理，高权低益令其满意，低权高益随时告知，低权低益监督。

## Key Concepts
- **互动沟通**（第4版术语，非"交互式沟通"）：会议、电话、即时消息。
- **沟通风格**：主动/被动、等级/协作。
- **会议管理**：会前议程、会中引导、会后纪要。

## Mental Models
- 噪声无处不在，**反馈闭环**才是有效沟通；选方法看"要不要即时双向"。

## Anti-patterns
- **用"交互式沟通"旧词**——第4版称"互动沟通"。
- **算错渠道数**——记住公式 n(n−1)/2，别漏算或重复。

## Key Takeaways
1. 沟通 3 过程。
2. 沟通模型五环节 + 噪声。
3. 三类沟通方法及适用。
4. 渠道数公式与权力/利益方格。
