# Chapter 16: 项目采购管理（3 过程）

## Core Idea
3 过程：**规划采购管理 / 实施采购 / 控制采购**；**合同类型选择 = 风险分配**是核心。

## Frameworks Introduced
- **三类合同**：
  - 总价类（FFP 固定总价 / FPIF 固定价激励 / FP_EPA 总价浮动）：买方风险小。
  - 成本补偿类（CPFF 成本加固定费 / CPIF 成本加激励 / CPAF 成本加奖励）：卖方风险小。
  - 工料（T&M）：混合，量不确定时适用。
- **FPIF 激励公式**：最终价 = 实际成本 + 目标费 ± 分摊比例×(目标成本−实际成本)（受价格上限约束）。
- **采购文件**：招标文件、工作说明书 SOW、独立估算（乙方报价比对）。

## Key Concepts
- **实施采购**：招标、评标、签合同、合同交底。
- **控制采购**：合同履约监控、变更（走合同变更，非项目变更流程）、索赔、合同收尾。
- **卖方违约处理**：先书面通知 + 给定补救期，再视情终止。

## Mental Models
- 选合同类型本质是**分风险**：范围明确选总价，范围模糊选成本补偿。

## Anti-patterns
- **FPIF 分摊计算漏掉价格上限**——激励价有封顶，超出由卖方自担。
- **合同变更误走项目变更流程**——采购变更走合同双方约定，不等同于 CCB 流程。

## Key Takeaways
1. 采购 3 过程。
2. 三类合同及风险分担方向。
3. FPIF 激励公式与价格上限。
4. 卖方违约处理顺序。
