# Chapter 11: 项目成本管理（4 过程）

## Core Idea
成本管理 = 规划 / 估算 / 制定预算 / 控制；**挣值管理（EVM）** 是综合+案例必考计算。

## Frameworks Introduced
- **4 个过程**：① 规划成本管理 ② 估算成本 ③ 制定预算 ④ 控制成本。
- **挣值 EVM**：三基准 EV（实现价值）/ PV（计划价值）/ AC（实际成本）；偏差 CV=EV−AC、SV=EV−PV；指数 CPI=EV/AC、SPI=EV/PV（<1 不好）。
- **预测**：EAC = BAC/CPI（典型偏差，考试默认）/ ETC = EAC−AC；非典型时 EAC = AC + BAC − EV。

## Key Concepts
- **成本基准** = 项目预算 − 管理储备（不含管理储备）；加上管理储备 = 项目总预算。
- **应急储备**（含于基准，应对已知未知）vs **管理储备**（不含基准，应对未知未知，动用需变更）。
- **TCPI** = (BAC−EV)/(BAC−AC) 或 (BAC−EV)/(EAC−AC)，衡量剩余成本绩效要求。

## Mental Models
- 看 CPI 判"钱超没超"，看 SPI 判"进度落没落"；**考试默认典型偏差**除非明说"后续按原计划"。

## Anti-patterns
- **把管理储备计入成本基准**——管理储备不进基准，动用须走变更。
- **非典型当典型**——未看清题干"剩余按原计划"就套 BAC/CPI。

## Key Takeaways
1. 成本 4 过程。
2. EVM：CV/SV/CPI/SPI 四指标 + EAC/ETC 两公式。
3. 成本基准不含管理储备。
4. 应急 vs 管理储备区别。
