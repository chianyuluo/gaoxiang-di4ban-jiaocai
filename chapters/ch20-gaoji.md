# Chapter 20: 高级项目管理

## Core Idea
面向大型/复杂与组织级：区分**项目组合（做哪些）、项目集（成组收益）、项目（交付）**三层，引入量化管理。

## Frameworks Introduced
- **三层关系**：项目组合管理（选择/优先级/战略对齐）→ 项目集管理（关联项目协同、实现收益）→ 项目管理（单项目交付）。
- **大型及复杂项目**：留较大余量、结构化分解、简化流程、强化控制。
- **量化项目管理**：六西格玛（DMAIC）、CMMI 成熟度、统计过程控制。
- **组织级项目管理 OPM**：与组织战略对齐的能力体系。

## Key Concepts
- **项目组合 vs 项目集**：组合管"该不该做哪些"（取舍），项目集管"成组项目如何协同出收益"（非简单相加）。
- **收益实现**：项目集的核心价值在于"收益"，而非单项目交付。

## Mental Models
- **组合 = 选篮子，项目集 = 管一篮子鸡蛋的协同收益，项目 = 孵一个蛋**。

## Anti-patterns
- **用管理单项目的方式管项目集**——忽视跨项目依赖与整体收益，是大型项目失败常见根因。

## Key Takeaways
1. 组合 / 集 / 项目三者区别与层级。
2. 大型复杂项目的管理要点（余量、分解、控制）。
3. 量化管理（六西格玛、CMMI）基本理念。
