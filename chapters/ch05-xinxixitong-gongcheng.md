# Chapter 5: 信息系统工程

## Core Idea
软件工程、数据工程、系统集成、安全工程是把技术变成可用系统的四类工程化手段，强调"可管控、可复用、可交付"。

## Frameworks Introduced
- **软件工程（6 活动）**：需求分析 / 软件设计 / 软件实现 / 部署交付 / 过程管理（含架构设计）。
- **数据工程（5 环节）**：数据建模 / 数据标准化 / 数据运维 / 数据开发利用 / 数据库安全。
- **系统集成**：网络集成 / 数据集成 / 软件集成 / 应用集成。
- **安全工程**：安全系统架构、安全生命周期。

## Key Concepts
- **需求工程**：需求获取、分析、定义、验证。
- **软件架构**：构件、连接件、约束。
- **ETL**：抽取-转换-加载（数据集成的核心）。
- **数据标准化**：元数据、主数据管理。

## Mental Models
- 工程化 = **用过程约束不确定性**：每个工程都有可定义的活动与交付物。

## Anti-patterns
- **跳过需求直接开发**——需求分析是软件工程的根，教材强调需求变更失控是项目失败主因。

## Key Takeaways
1. 软件工程 6 活动。
2. 数据工程 5 环节（尤其 ETL）。
3. 系统集成四种集成类型。
4. 安全工程的体系视角。
