# Chapter 15: 项目风险管理（7 过程）

## Core Idea
7 过程贯穿"识别→定性→定量→应对→实施→监督"；**威胁四策 / 机会四策**对称，应急计划带触发条件。

## Frameworks Introduced
- **7 个过程**：① 规划风险管理 ② 识别风险 ③ 实施定性风险分析 ④ 实施定量风险分析 ⑤ 规划风险应对 ⑥ 实施风险应对 ⑦ **监督风险**（第4版名，非"风险监控"）。
- **定性分析**：概率×影响矩阵、风险数据质量评估、紧迫性。
- **定量分析**：EMV/决策树（ch21）、蒙特卡洛模拟、敏感性分析（龙卷风图）。
- **应对策略**：威胁=规避/转移/减轻/接受；机会=开拓/分享/提高/接受。
- **应急计划**（带触发条件）vs **弹回计划**（主计划失效备选）——第4版用"应急计划+触发条件"替代旧"权变措施"。

## Key Concepts
- **风险登记册**：风险描述、成因、影响、应对措施。
- **整体项目风险** vs **单个风险**。
- **接受策略**：被动接受（不行动）/ 主动接受（留应急储备）。

## Mental Models
- 威胁四策与机会四策**镜像对称**；EMV 决策选期望收益大者。

## Anti-patterns
- **用"风险监控 / 权变措施"旧词**——第4版为"监督风险""应急计划+触发条件"。
- **接受=躺平**——主动接受应配套应急储备或应急计划。

## Key Takeaways
1. 风险 7 过程（监督风险）。
2. 定性 vs 定量分析方法。
3. 威胁四策 / 机会四策。
4. 应急计划 vs 弹回计划。
