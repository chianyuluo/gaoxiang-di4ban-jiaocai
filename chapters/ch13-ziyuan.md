# Chapter 13: 项目资源管理（6 过程）

## Core Idea
第4版资源管理**含"估算活动资源"**（从进度章划过来）；既管人（团队）也管实物资源。

## Frameworks Introduced
- **6 个过程**：① 规划资源管理 ② **估算活动资源** ③ 获取资源 ④ 建设团队 ⑤ 管理团队 ⑥ 控制资源。
- **责任分配矩阵 RAM / RACI**：R(执行) A(负责) C(咨询) I(知情)。
- **团队发展塔克曼阶梯**：形成 → 震荡 → 规范 → 成熟 → 解散（冲突在震荡期最烈）。
- **冲突解决 5 法**：撤退/回避、缓解/包容、妥协/调解、强迫/命令、合作/解决问题。
- **激励理论**：马斯洛需求层次、赫茨伯格双因素、麦克利兰成就动机、期望理论。

## Key Concepts
- **建设团队**（第4版术语，非"建设项目团队"）：培训、团建、集中办公、虚拟团队。
- **虚拟团队**：沟通成本与信任建设是难点。
- **资源日历**：资源可用时间。

## Mental Models
- 团队按**塔克曼五阶段**演进，震荡期冲突正常；解决冲突首选"合作/解决问题"。

## Anti-patterns
- **用"建设项目团队"旧称**——第4版统一为"建设团队"。
- **低估虚拟团队沟通成本**——分布式团队需额外约定沟通节奏与信任机制。

## Key Takeaways
1. 资源 6 过程（含估算活动资源）。
2. RACI 含义与用法。
3. 塔克曼五阶段 + 冲突五法。
4. 三大激励理论。
