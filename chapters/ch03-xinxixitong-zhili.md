# Chapter 3: 信息系统治理

## Core Idea
IT 治理解决"方向、权责、价值"，IT 审计做"监督、评价、合规"——治理是分权制衡，审计是独立核查。

## Frameworks Introduced
- **IT 治理体系（组件）**：决策（谁决定）/ 执行（谁实施）/ 监督（谁评价）三层，遵循"战略一致性、价值交付、风险管理、资源优化、绩效透明"目标。
- **IT 治理任务**：统筹规划、组建机构、明确权责、构建机制、制定制度。
- **IT 审计流程**：审计准备 → 审计实施 → 审计报告 → 后续审计（4 阶段）。
- **IT 审计内容**：总体审计、系统审计、专项审计。

## Key Concepts
- **IT 治理 vs IT 管理**：治理定方向/分权责（董事会层），管理抓落实/管执行（经理层）。
- **COBIT**：主流 IT 治理框架。
- **审计方法**：访谈、文档审查、日志分析、技术测试。

## Mental Models
- 治理 = **分权与问责**（决策/执行/监督三权分离）；审计 = **独立第三方视角**查合规与风险。

## Anti-patterns
- **把 IT 治理等同于"管 IT 部门"**——治理是董事会/高管层的战略权责安排，不是部门内部事务。

## Key Takeaways
1. IT 治理三大组件与五大目标。
2. IT 审计四阶段流程名称与顺序。
3. 治理与管理本质区别。
