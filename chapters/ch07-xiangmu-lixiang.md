# Chapter 7: 项目立项管理

## Core Idea
立项是从"项目建议"到"投资决策"的门：核心是**可行性研究**，回答"该不该做、值不值得做"。

## Frameworks Introduced
- **立项流程**：项目建议与立项申请 → 可行性研究（概要/详细）→ 项目评估与决策。
- **可行性研究维度**：技术、经济、运行环境、法律、社会、市场、财务等。
- **经济可行性指标**：净现值 NPV、投资回收期、投资收益率（详见 ch21）。

## Key Concepts
- **项目建议书（初步可行性）**：论项目的必要性与大致可行。
- **详细可行性研究**：技术/经济/运行/法律/社会全面论证。
- **项目评估 vs 论证**：论证是"乙方说能做"，评估是"甲方/第三方独立审"。
- **决策**：基于评估结果的 go / no-go。

## Mental Models
- 立项是**价值前置过滤门**：不划算/不可行的项目在这个阶段就该被否掉。

## Anti-patterns
- **跳过详细可行性直接开工**——教材强调详细可行性是决策依据，仓促立项导致后期范围与成本失控。

## Key Takeaways
1. 立项三阶段顺序：建议 → 可行性 → 评估决策。
2. 可行性研究的多个维度。
3. 论证（乙方）与评估（独立）的区别。
