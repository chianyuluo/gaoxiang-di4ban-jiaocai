# Chapter 23: 组织通用管理

## Core Idea
项目经理需懂组织通用职能：市场营销、人力资源、财务、行政与法律法规，便于跨部门协同与商业论证。

## Frameworks Introduced
- **市场营销**：STP（细分/目标/定位）+ 4P（产品/价格/渠道/促销）。
- **人力资源管理**：招聘选拔、绩效、薪酬激励、培训发展。
- **财务管理**：预算编制、成本控制、投资评价（与 ch21 经济评价呼应）。
- **行政管理**：办公、后勤、制度流程。
- **组织级项目管理 OPM**：组织把项目管理作为常态能力的成熟度体系。

## Key Concepts
- **商业论证 / 立项衔接**：市场与财务分析支撑项目存在的合理性。
- **OPM 成熟度**：组织项目管理能力分级（初始→标准→可度量→管控→优化）。

## Mental Models
- 项目经理是**跨界接口人**：懂各职能语言，才能争取资源、对齐目标。

## Anti-patterns
- **只懂技术不懂商业**——高项强调"战略与商业管理"能力，论文/案例常考商业论证与收益。

## Key Takeaways
1. 市场营销 STP+4P。
2. 人力资源四模块。
3. 财务管理与 ch21 经济指标衔接。
4. OPM 成熟度概念。
