# Chapter 21: 项目管理科学基础（计算重镇）

## Core Idea
工程经济 + 运筹学：是综合/案例的**计算题来源**，2025起案例还把博弈、指派、线性规划纳入。

## Frameworks Introduced
- **工程经济**：资金时间价值（现值 P / 终值 F / 年金 A）；评价指标 **NPV（净现值，>0 可行）、IRR（内部收益率，>基准可行）、投资回收期、ROI（投资收益率）**。
- **网络计划技术**：双代号/单代号网络图、关键路径法 CPM（与 ch10 衔接）。
- **线性规划**：图解法求可行域顶点最优解。
- **运输问题 / 指派问题**：指派用**匈牙利算法**（行减 → 列减 → 划线覆盖 → 调整）。
- **博弈论**：两人零和，用**极大极小法**求鞍点（各方都选最不利情形下的最优）。
- **决策论**：决策树 / **EMV（期望货币值）** = Σ(概率×结果)，选 EMV 大者；贝叶斯后验概率。

## Key Concepts
- **复利公式**：F = P(1+i)ⁿ、P = F/(1+i)ⁿ；年金现值和。
- **NPV 判别**：NPV ≥ 0 接受，IRR ≥ 基准收益率接受。
- **匈牙利算法思路**：使每行每列出现 0 且独立 0 数 = 任务数即最优。

## Mental Models
- 经济题先问"要算可行性还是比方案"→ NPV/IRR/回收期；博弈题先找鞍点；指派题先画 0 矩阵。
- **考试默认 EVM 典型偏差**（CPI 持续），除非明说"后续按原计划"。

## Anti-patterns
- **指派题忘记匈牙利"行减列减"标准化**——直接凭感觉配对会算错。
- **把 EMV 当单值决策**——必须比较各方案期望，且考虑风险态度（风险厌恶者可能不选 EMV 最大）。

## Key Takeaways
1. 四类经济评价指标及判别规则。
2. 运筹五类题型（网络/线性/运输/指派/博弈）的方法论名称。
3. EMV / 决策树 / 贝叶斯基本思路。
4. 匈牙利算法步骤。
