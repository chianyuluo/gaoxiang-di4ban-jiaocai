# Chapter 12: 项目质量管理（3 过程）

## Core Idea
质量 3 过程：**规划质量管理**（定标准）→ **管理质量**（过程保证）→ **控制质量**（结果检查），二者分工不能混。

## Frameworks Introduced
- **3 个过程**：① 规划质量管理 ② 管理质量 ③ 控制质量。
- **管理质量（QA 思维）**：审计、设计评审、过程改进、PDCA——面向"过程是否可靠"。
- **控制质量（QC 思维）**：测试、抽检、检查、七种质量工具——面向"可交付物是否合格"。
- **质量成本 COQ**：预防成本 / 评估成本 / 内部失败成本 / 外部失败成本。

## Key Concepts
- **规划质量管理**：输出质量管理计划、质量测量指标、核对单。
- **全面质量管理 TQM / 六西格玛 / 精益**：主流质量理念。
- **七种质量工具**（老七工具：因果图、流程图、核查表、帕累托图、直方图、控制图、散点图）。

## Mental Models
- 管理质量 = **"做对的事"**（过程可靠）；控制质量 = **"做的对不对"**（结果合格）。

## Anti-patterns
- **倒置管理与控制质量**——把"没做质量审计"误判为"没做测试"，案例找错常设此坑。
- **忽视质量成本四类划分**——预防/评估是"投入"，失败是"损失"，重预防更经济。

## Key Takeaways
1. 质量 3 过程及管理 vs 控制质量区别（高频考点）。
2. 质量成本四类。
3. 老七工具名称（注意：第4版论文/案例慎用"帕累托图"旧表述，按教材为准）。
