# Chapter 6: 项目管理概论

## Core Idea
第4版用"价值驱动的项目管理知识体系"统摄全局：**12 条原则 + 5 大过程组 + 项目生命周期 + 8 个绩效域 + 价值交付系统**，绩效域是新增核心。

## Frameworks Introduced
- **价值驱动体系五大件**：① 12 条原则 ② 5 大过程组（启动/规划/执行/监控/收尾）③ 项目生命周期与阶段 ④ **8 个绩效域** ⑤ 价值交付系统。
- **12 条原则**：管家精神、协作环境、有效沟通、整合动态、领导力、识别管理风险、优化风险应对、按需裁剪、收尾创值、保持合规、拥抱适应韧性、赋能成果。
- **项目经理能力**：技术项目能力 / 领导力能力 / 战略和商业管理能力（三类）。

## Key Concepts
- **项目成功标准**：交付成果、商业价值、干系人满意度。
- **8 个绩效域**（总览）：干系人/团队/开发方法和生命周期/规划/项目工作/交付/度量/不确定性（详见 ch18）。
- **裁剪**：依项目背景调整过程与治理。

## Mental Models
- 项目是**价值交付载体**：不要只盯"按时按预算"，还要看"预期成果是否实现"。
- 第4版视角切换：传统"过程组" + 新增"绩效域"两条线都要会用。

## Anti-patterns
- **死记过程组、忽视绩效域**——第4版命题重点明显向绩效域倾斜，案例与论文都考绩效域应用。

## Key Takeaways
1. **12 条原则必须能列出**（选择题高频）。
2. **8 个绩效域名称**（ch18 详解）。
3. 5 大过程组名称与顺序。
4. 项目经理三类能力模型。
