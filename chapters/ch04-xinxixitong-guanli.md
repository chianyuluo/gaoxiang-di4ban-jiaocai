# Chapter 4: 信息系统管理

## Core Idea
用"规划组织 → 设计实施 → 运维服务 → 优化改进"的方法论管信息系统；数据管理、运维管理、信息安全管理是三大要点。

## Frameworks Introduced
- **管理方法（生命周期 5 步）**：规划和组织 / 设计和实施 / 运维和服务 / 优化和持续改进（另含管理基础）。
- **管理要点三块**：数据管理（数据治理、数据标准）/ 运维管理（ITIL 服务理念）/ 信息安全管理（策略、组织、技术）。

## Key Concepts
- **数据管理**：数据治理、数据架构、数据标准、数据安全。
- **IT 服务管理（ITIL）**：以服务为中心，事件/问题/变更/配置/发布管理。
- **信息安全管理体系（ISMS）**：PDCA 循环、纵深防御。

## Mental Models
- 管理是**闭环循环**：规划→实施→运维→优化，周而复始，不是一次性项目。

## Anti-patterns
- **重建设轻运维**——教材强调运维与服务是价值兑现期，IT 资产的大部分成本与风险在运维阶段。

## Key Takeaways
1. 管理方法 5 步阶段名。
2. 三大管理要点：数据 / 运维 / 安全。
3. ITIL 服务管理核心理念。
