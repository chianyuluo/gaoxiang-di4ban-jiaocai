# Chapter 24: 法律法规与标准规范

## Core Idea
招投标、政府采购、合同、著作权、标准与知识产权——既是选择题考点，也是案例/论文的合规底线。

## Frameworks Introduced
- **招标投标法**：公开招标 / 邀请招标 / 竞争性谈判；评标委员会；废标条件；投标有效期与投标保证金；中标通知书。
- **政府采购法**：六种方式（公开招标、邀请、竞争性谈判、单一来源、询价、国务院认定的其他方式）。
- **合同法**：要约/承诺（合同成立）、合同效力（生效/无效/可撤销）、履行、违约救济（继续履行/赔偿/解除）、索赔时效。
- **著作权法**：职务作品（单位任务内、主要利用单位资源）→ **著作权归单位**；委托作品依约定。
- **标准规范**：国家标准 GB / 行业标准 / 地方标准；强制性 vs 推荐性。
- **知识产权**：专利、商标、商业秘密保护。

## Key Concepts
- **投标保证金 / 履约保证金**：金额上限与退还规则（法定比例，选择题常考）。
- **合同违约救济顺序**：先催告/补救，再视情解除并索赔。
- **职务作品归属**：一般归单位，例外（非职务、自利用）归作者。

## Mental Models
- 合规底线 = **程序正义 + 权责明确**：招投标程序错一步即废标，合同违约先补救再解除。

## Anti-patterns
- **混淆公开招标与邀请招标适用情形**——金额达标必须公开，特殊情形才可邀请/单一来源。
- **以为委托作品著作权天然归委托方**——无约定时归受托方，务必书面约定。

## Key Takeaways
1. 招投标三种主要方式及废标条件。
2. 政府采购六种方式。
3. 合同成立（要约/承诺）与违约救济。
4. 职务作品著作权归属规则。
5. 标准分级（国/行/地）与强制性区分。
