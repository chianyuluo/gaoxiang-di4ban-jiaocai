# Chapter 22: 组织通用治理

## Core Idea
在组织层面建立"规则—责任—监督"的治理框架，并用度量体系保证战略落地；与第3章 IT 治理一脉相承。

## Frameworks Introduced
- **治理框架三要素**：规则与政策、责任与职权、监督与制衡。
- **治理过程**：治理设计 → 治理运行 → 治理评估（持续改进）。
- **度量体系**：以平衡计分卡等将战略分解为可度量指标（财务/客户/内部流程/学习成长）。

## Key Concepts
- **治理 vs 管理**：治理定方向、分权责、做监督（董事会/高管层）；管理抓落实、管执行（经理层）。
- **治理运行机制**：决策机制、激励机制、监督机制。

## Mental Models
- 治理 = **组织的"宪法+制衡"**：没有监督的权责会失控。

## Anti-patterns
- **把组织治理等同于日常经营管控**——治理是战略与权责安排，不是运营细节管理。

## Key Takeaways
1. 治理框架三要素。
2. 治理过程三阶段。
3. 度量体系（平衡计分卡四维度）。
