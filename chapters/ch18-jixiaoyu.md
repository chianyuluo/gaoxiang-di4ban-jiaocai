# Chapter 18: 项目绩效域（8 个绩效域）

## Core Idea
第4版**核心新增**章节：用 8 个成果导向的"绩效域"补充传统过程组视角，二者**相互映射**，答题要能切换。

## Frameworks Introduced
- **8 个绩效域**：
  1. **干系人绩效域** — 建立信任、持续参与。
  2. **团队绩效域** — 高绩效团队、领导力、安全文化。
  3. **开发方法和生命周期绩效域** — 选预测/混合/适应（敏捷）方法。
  4. **规划绩效域** — 估算、项目结构、预算与进度。
  5. **项目工作绩效域** — 过程管理、变更、阶段关口、持续学习。
  6. **交付绩效域** — 交付价值、质量、可交付物验收。
  7. **度量绩效域** — 度量指标（PMC、工作量、进度、成本、质量、客户满意度等），用数据决策。
  8. **不确定性绩效域** — 风险 + 模糊，韧性应对。
- **映射关系**：每个绩效域与多个十大管理过程相对应（如"交付绩效域"↔ 范围/质量/进度/收尾过程）。

## Key Concepts
- **绩效域 vs 过程组**：过程组是"动作序列"，绩效域是"成果领域"，互补而非替代。
- **开发方法选择**：预测（需求稳）、适应/敏捷（需求变）、混合。
- **度量指标族**：进度偏差、成本偏差、质量指标、客户满意度。

## Mental Models
- 问"怎么管团队"→ 团队绩效域 + 资源管理过程；问"如何应对变化"→ 不确定性绩效域。
- 绩效域 = **以成果衡量管理有效性**，不只看"做了没做过程"。

## Anti-patterns
- **把绩效域当独立章节、不联系十大管理**——命题常考"某绩效域对应哪些过程"。
- **忽视 8 个绩效域名称背诵**——这是第4版与第3版最大的区分点，论文/案例都考。

## Key Takeaways
1. **背熟 8 个绩效域名称与顺序**（极高概率考点）。
2. 每个域的"预期目标"要点。
3. 绩效域与十大管理过程的映射关系。
4. 开发方法三类及适用场景。
