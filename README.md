# 软考高项（信息系统项目管理师）第 4 版 · 备考 Skill

> 把《信息系统项目管理师教程（第 4 版）》结构化提炼而成的 agent skill，供 WorkBuddy / Claude 等支持 skills 的 AI 助手调用，辅助软考高项备考（知识点梳理、案例找错、论文技法、考点速记）。

## 这是什么
- **不是教材原文，而是框架型提炼**：每章抽取 Core Idea / Frameworks / Key Concepts / Mental Models / Anti-patterns / Takeaways，便于快速取料与出题。
- 覆盖：24 章知识框架、**8 个绩效域**、十大管理 ITTO、速记清单、术语表、案例反模式、论文写作技法。

## 目录结构
- `SKILL.md`：主索引（框架 / 原则 / 技法 / 反模式层）
- `chapters/ch01~ch24.md`：24 章结构化笔记
- `cheatsheet.md`：公式 / 过程数 / 决策规则速查
- `glossary.md`：核心术语
- `patterns.md`：案例找错反模式 / 论文技法 / 计算套路
